# Triage labels

| Role / tracker label | Meaning |
| --- | --- |
| needs-triage | Maintainer needs to evaluate the issue |
| needs-info | Waiting for more information |
| ready-for-agent | Fully specified for agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Use these exact label strings whenever a skill names a triage role.
Readiness labels do not grant workload, hardware or elevation permission.
